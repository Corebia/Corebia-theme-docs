# Support

Pave is supported directly by Corebia. This page is where the theme's **Support** link in your Shopify admin brings you.

## Get help

[Contact us](contact/){: .btn .btn-primary }

We reply within **2 business days**. Anything that takes a storefront offline or blocks checkout is treated as critical and handled immediately.

## Before you write

Two things answer most questions faster than we can:

- **[FAQ](faq/)** — the questions we get most often, with answers.
- **The documentation** — every setting in the theme is documented, under [Theme settings](../theme-settings/), [Sections](../sections/) and [Templates](../templates/). If a setting isn't doing what you expect, its page will usually say why.

## What support covers

In short: the theme, as it ships. Bugs, broken layouts, questions about how a setting works, and help getting set up.

It does not cover code you or a developer have added, third-party apps, or custom design work. The full boundary is in the [support policy](support-policy/), which is worth reading before you commission changes to the theme.

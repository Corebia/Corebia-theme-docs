# Rich text with image

The **Rich text with image** section pairs an image with stacked content blocks (heading, text, button). It is the flexible storytelling section — use it for an "about us", a sustainability page, or a product narrative.

## Settings

- **Image** — The accompanying photograph.
- **Image position** — Whether the image appears on the **Left** or the **Right**.

The section also exposes color scheme and spacing settings that apply globally to it.

## Blocks

Add blocks via **Add heading**, **Add text**, or **Add button**. Order blocks however you like; they stack vertically next to the image. Maximum 6 blocks.

### Heading

- **Heading** — The text of the heading. Default: `Our story`.

### Text

- **Text** — Rich text body. Default: `Share your brand story with customers. Describe a product, make announcements, or welcome customers to your store.`

### Button

- **Label** — The button text. Default: `Learn more`.
- **Link** — The URL the button points to.
- **Style** — Visual style. Options: **Primary** (filled), **Secondary** (outline).

## Tips

- **Stack matters.** A typical pattern is heading → text → button. Reorder blocks by dragging them in the editor.
- **Two-color buttons** — If you have multiple buttons in one section, use one **Primary** and one **Secondary** for hierarchy.
- **Image size** — Square or 4:5 portrait images work best. The image area maintains aspect ratio with the text column.
- **Pair with a brand message** — If you want a denser story, alternate **Brand message** and **Rich text with image** sections to break the rhythm.

# Section

**Section** is a blank section you build yourself from [theme blocks](../theme-blocks/): headings, text, buttons, images, icons, videos, countdowns, groups that arrange blocks in rows or columns, dividers, spacers and app blocks. Use it when none of the purpose-built sections has the layout you want.

It can be placed on any template and in the footer group, but not in the header group.

## Presets

When you add a section, the editor offers ready-made starting points. All of them are this same section with different blocks already in place, so everything in them can be changed afterwards.

- **Section.** A group with a heading and text.
- **Video.** A video followed by a heading and text.
- **Icons with text.** Three columns, each an icon, a heading and text, set up for shipping, returns and secure checkout.
- **Multicolumn.** Three columns of heading and text.
- **Stats.** Three large figures, each with a label.
- **Jumbo text.** One line of text sized to fill the page width.
- **Logos.** A heading over a row of five images.
- **Countdown.** A heading, text, a countdown and a button.
- **Image compare.** A heading and text above a before and after comparison slider.

Every preset ships with sample copy. It is shown to customers, so replace it before you publish.

## Settings

- **Color scheme.** Default: scheme-1.
- **Content width.** **Full width** (default) or **Reading column**. **Reading column** narrows the section to the column of a page's body text and sets its headings and text as they are in a page body, so a section placed under a page's title and body reads as part of it. Several of the [alternate page templates](../../templates/page-templates/) use it.
- **Top padding** / **Bottom padding.** Range: 0 to 300 px in 5 px steps. Default: 60 px each.

## Blocks

Every [theme block](../theme-blocks/), app blocks, and the [Divider](../theme-blocks/#divider). Blocks stack in the order you arrange them. To put blocks side by side, add a [Group](../theme-blocks/#group), set its **Direction** to **Horizontal**, and add the blocks inside it.

## Tips

- **Start from the closest preset.** Rebuilding a three-column layout from an empty section takes several steps; the Multicolumn preset starts there.
- **Set nested groups to Fill.** In a horizontal group, child groups set to **Width: Fill** share the row equally and stack on narrow screens, which is how the column presets work.
- **Use Reading column for prose under a page.** A statement, an introduction or instructions below the Main page section line up with the page's title and text instead of running the full width.
- **Check it on a phone.** Horizontal groups wrap on small screens. Look at the result at phone width before publishing.

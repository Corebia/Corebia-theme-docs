# Sections

Sections are the building blocks of every page in Pave. Most sections can be added, removed, and reordered from the theme editor without touching code.

The pages below document every section the theme ships, in alphabetical order. The **Header** and **Footer** are global — they appear on every page. The other sections can be added to compatible templates.

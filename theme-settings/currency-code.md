# Currency code

Whether prices carry their three-letter currency code, as in `$10.00 CAD` rather than `$10.00`. Several currencies share the `$` symbol, so the code is what tells a shopper which one they are browsing in.

Each place prices appear has its own switch.

## Settings

- **Show on product pages.** Default: on.
- **Show on product cards.** Applies to every card: collections, search, recommendations, recently viewed and the search drawer. Default: on.
- **Show on cart line items.** Applies to the price of one item and to the line total. Default: on.
- **Show on the cart total.** Default: on. Shopify recommends leaving this on: cart and checkout totals should always name the currency, so there is no confusion when the shopper places the order.

## Tips

- **Leave the cart total on in every case.** It is the number the shopper commits to, and it should never be ambiguous.
- **Consider turning cards off if you sell in one currency.** A store that sells only in euros to one country gains little from `EUR` on every card, and a grid reads cleaner without it.
- **Keep them on if you sell internationally.** A shopper from Canada seeing `$` on a US store needs the code to know whether that price is theirs. See [Multi-currency and language](../../features/multi-currency-language/).

# Cart settings

The **Cart** category in **Theme settings** controls behaviors of the cart that apply globally.

## Settings

- **Enable discount code field** — When enabled, the cart page shows a field where the customer can enter a discount code before reaching checkout. Default: enabled.

## Recommendations

- **Leave the discount code field enabled** unless you exclusively distribute discount codes via automatic application or post-checkout. Cutting it off can frustrate customers who have a code in hand.
- **Discount codes vs. automatic discounts:** Discount codes are codes a customer types in. Automatic discounts (configured in `Shopify admin > Discounts`) apply at checkout based on cart conditions and don't need a code. The toggle here only affects the customer-typed code field. Automatic discounts always apply.

## Where the field appears

When enabled, the discount code field appears in the cart summary above the checkout button on the cart page. See [Discount codes](../../features/discounts/) for the full discount story across cart, checkout, and order summary.

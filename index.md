# Pave theme documentation
{: .fs-9 }

Pave is an editorial Shopify theme by Corebia, built for stores that lead with photography. It suits fashion, lifestyle and homeware merchants who want a spacious, gallery-like storefront.
{: .fs-5 .fw-300 }

### Configure the theme

Settings that apply everywhere at once. Worth getting right before you build pages.

- [Colors](theme-settings/colors/): Color schemes, used by every section, and dark mode.
- [Typography](theme-settings/typography/): Fonts and the size of each heading level.
- [Layout](theme-settings/layout/): Page width.
- [Buttons](theme-settings/buttons/), [Input fields](theme-settings/input-fields/) and [Popovers and drawers](theme-settings/popovers/): Borders, corners and shadows.
- [Icons](theme-settings/icons/): Icon stroke weight.
- [Social media](theme-settings/social-media/): Profile URLs behind the social icons.
- [Logo](theme-settings/logo/): Logo image, widths and the inverse logo.
- [Favicon](theme-settings/favicon/): Browser icon and social share image.
- [Cart settings](theme-settings/cart-settings/): Cart drawer or page, free shipping bar, suggestions and gift wrap.
- [Discount display](theme-settings/discount-display/): How sale badges are written and colored.
- [Badges](theme-settings/badges/): Badge position, shape and tag badges.
- [Product cards](theme-settings/product-cards/): Card style, image ratio, quick add, quick view and swatches.
- [Variant picker](theme-settings/variant-picker/): Swatch style, controls and out-of-stock behavior.
- [Search](theme-settings/search/): What the search drawer shows before a shopper types.
- [Currency code](theme-settings/currency-code/): Where prices show `CAD`, `USD` and so on.
- [Animations](theme-settings/animations/): Page transitions, card hover and reveal on scroll.
